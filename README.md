# Daily Bloom 2.0 🌷

مخطط شخصي عربي ومتجاوب للمهام والعادات والتمارين، مبني كتطبيق ويب تقدمي (PWA) بدون Backend أو خدمة مزامنة.

## الوظائف
- مهام يومية وأسبوعية ولمرة واحدة.
- إنجاز المهمة أو تخطيها لتاريخ واحد أو إنهاء تكرارها من تاريخ محدد أو حذف السلسلة.
- تعديل نسخة اليوم فقط أو تعديل المهمة من اليوم وما بعده.
- تصنيفات وأولويات وترتيب يدوي بالسحب والإفلات أو أزرار الترتيب على الهاتف.
- تقويم شهري يوضح المهام والعادات والتمارين لكل يوم.
- سجل جلسات رياضية وتمارين ومجموعات وعدات وأوزان، مع متابعة إنجاز كل مجموعة.
- عادات يومية أو أسبوعية مع سجل التزام وسلسلة أيام.
- حفظ البيانات على الجهاز باستخدام IndexedDB.
- دعم العمل دون اتصال بعد فتح الموقع وتحميل ملفاته أول مرة.

## التخزين والخصوصية
لا يوجد Backend أو Cloud أو مزامنة. تخزن بيانات التطبيق محلياً في IndexedDB داخل المتصفح وعلى نفس الجهاز/ملف المتصفح. حذف بيانات الموقع من إعدادات المتصفح أو إزالة بيانات Safari قد يؤدي إلى حذف بيانات التطبيق. لا يتطلب التطبيق حساباً أو إشعارات.

عند أول تشغيل، يحاول التطبيق نقل مهام النسخة السابقة الموجودة في `localStorage` (المفتاح `daily-bloom-v1`) إلى IndexedDB تلقائياً.

## النشر على Netlify
- Build command: اتركيه فارغاً.
- Publish directory: `.`
- Branch: `main`.

كل تحديث على `main` يؤدي إلى نشر إصدار جديد عند تفعيل النشر التلقائي في Netlify.
